# 表达方式与视觉风格

风格是可组合的选择，不是按平台贴标签。先确定受众、资料与目的，再选表达、视觉、语气；参考链接或用户自定义描述优先于预设。目录中的预设用于指导，不能当作渲染器已经实现了相应版式。

## 表达方式

| 方向 | 适用任务 | 关键要求 |
| --- | --- | --- |
| 解释科普 explainer | AI 原理、科学问题、概念解释 | 一个问题、机制与例子；说明类比边界，避免堆术语 |
| 实操教程 tutorial | 工具上手、效率方法、生活技巧 | 可复现的前提、步骤、结果与失败点 |
| 实测对比 review | AI 工具/模型比较、产品选择 | 真实测试条件、评价维度、结果和限制；没有测试不写“亲测” |
| 案例场景 case-study | 自有产品宣传、使用案例、解决问题 | 问题—过程—真实结果，可说明适用者与取舍；不伪造客户案例 |
| 个人叙事 personal-story | 开发者手记、生活随笔、观点 | 真实细节、作者立场与明确感受；不代编经历 |
| 生活记录 documentary | 日常、手作、美食、出行、人物记录 | 人物、环境、过程和变化；不是把生活写成产品发布口播 |
| 产品发布 launch | 新功能、更新说明、产品发布 | 新变化、受众价值、真实演示与克制的品牌表达 |
| 轻松玩梗 humor | 有关联的幽默解释、反差表达 | 梗帮助理解，不覆盖事实，不强制所有内容追热点 |

## 视觉选项

编辑/杂志、知识卡片、手账拼贴、真实操作、自然纪实、动态设计分别用于不同阅读与观看任务。它们是本插件建议提供的创作选项，**不是当前全网热度排名**。字号、配色、留白、图片选择、图层和动效都需要按实际工具制作与检查。

例如：

- AI 实操：教程 + 真实操作；也可交付分步文章或截图贴图。
- 科普：解释 + 知识卡片/编辑排版；有演示素材时做解释视频。
- 自有产品：案例场景或发布 + 真实操作/编辑排版/动态设计，按目标选择。
- 生活：个人叙事或生活记录 + 自然纪实/照片组/手账拼贴；语气和形式依用户选择。

以上是组合建议，不要求用户照单选择。不要把“B站一定长视频”“公众号只能长文”“快手只能生活”写进创作规则。

## 如何使用趋势

已核对的趋势证据与日期见 [trends-2026-10.md](trends-2026-10.md)。公开资料支持关注实用解决方案、真实体验、个性与幽默表达；这些不等于某个配色、标题公式或剪辑技巧保证有效。

需要“近期热门”时，使用用户指定的浏览器能力调研相关领域的近期样本或报告，记录日期、来源、适用领域和证据范围。把观察到的样例特征、报告结论、自己的创意建议分别表述。搜索摘要、AI 搜索概览与模板站文案不能直接当作趋势证据。

没有同一时间窗口和可比较的曝光/互动数据时，不给“TOP 风格”排名，不臆测平台算法权重。风格库保留用户自定义和随时调整的空间，趋势不会自动覆盖已经确认的需求。
