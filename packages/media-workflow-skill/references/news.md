# 资讯型

先按受众和本次目的选择报道角度，再决定保留哪些事实。优先回答“发生了什么、与观众有什么关系、需要知道的条件是什么”，不默认照读原文或把所有信息等量罗列。深度解读、严肃报道与简报的节奏可以不同，视觉风格不由 news 这个类型决定。

事实表记录来源 ID、准确引述、原始事件时间与时区、数字单位、待核实事项、采集时间。来源发布时间、事件发生时间和本次信息截止时间分别保留；界面使用 Asia/Shanghai 展示本地业务时间，不替换原文时区。

优先原始公告、产品文档、官方发布和原始数据。标题、观点与预测应与已发生事实区分。数字口播化时保留相同数值和单位；不能把相关关系写成因果关系。

引述必须能在对应原文中定位。程序的引述匹配只能证明引用存在，不能证明来源本身真实或表述没有曲解。未知事项留在 unknowns，不编造来源链接、精确时间、作者或确认结论。

分镜注明每个关键表述使用的素材和来源。成片检查字幕、口播、数字、单位、时间与来源展示的一致性。词级时间轴应来自服务词边界或实际强制对齐，不能由字符平均分配冒充。

复用旧资讯案例时保留原始资料和当时截止时间，不把旧片作为当日新闻直接发布。历史样片只提供表达参考，不能作为新任务的事实证据或验收结论。
