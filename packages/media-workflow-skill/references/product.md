# 产品介绍型

先区分上手教程、功能演示、场景介绍和产品发布等用途。教程强调动作与反馈，演示强调真实结果，发布片强调变化与价值；不要把每次产品需求都写成口号加功能清单。视觉与节奏遵循用户目的及参考，具体制作路径见 [creation.md](creation.md)。

素材阶段取得产品真实界面截图或录屏、原始 Logo、品牌配色及出处。优先本地项目和已有素材，再使用实际产品页面。记录界面版本、素材来源、可用范围和采集时间。

每个分镜引用具体真实素材。屏幕上的功能、文字和数据应有对应证据。没有登录权限、素材不全或能力无法确认时明确列出缺失项；不能用相似产品推断能力。

Logo 使用原始文件。出现界面时使用真实截图/录屏，或由截图严格追踪且与原图对照的代码画面。禁止占位框、编造的 UI、重绘 Logo、未经声明的假数据。缺素材时阻塞对应环节，不自动替换成另一种较差画面。

可编辑工程保留真实素材引用、配色出处、分镜、时间轴与生成代码。检查标题、字幕和演示画面是否遮挡关键操作，预览首帧与切换后的画面；未真正观看的效果不能报告为视觉验收。
