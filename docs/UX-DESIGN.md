# 媒体工作流交互重设计

本轮保留完整制作能力，调整信息架构、操作顺序与显示密度。实现位于 0.1.1 本地版本；日常 DSH 仍运行原安装包。本轮不重启 DSH，不迁移、重建或修改正在执行的任务。

## 核心问题与决定

| 现状 | 对用户的影响 | 新交互 |
| --- | --- | --- |
| 聊天 CLI 自选任务根，插件读取另一目录 | 模型说已开始，工作台仍为空 | 设置提供工作目录；技能附带 Host 当前实际路径；列表自动发现同根新任务 |
| 任务、工作台、新建、设置四个同级标签 | 尚未选任务就出现无法进入的工作台 | 任务是首页；任务详情从具体任务进入；新建和设置是独立动作 |
| 右侧任务操作跳转全局页面 | 点击后离开当前对话 | 任务详情、评审、步骤与预览留在右侧，仅主动点击“展开”进入全局工作台 |
| 设置平铺模型、工具路径与默认项 | 首次使用需理解技术栈，难以定位目录 | 分为工作目录、制作偏好、发布账号、工具与诊断；路径默认折叠 |
| 新建一次展示所有字段 | 用户难以判断先填什么 | 内容与资料 → 交付规格 → 确认并开始，草稿随时保存 |
| 状态展示偏向执行器 | 知道“blocked”，不知道该做什么 | 用户状态加一句明确下一步，并保留详细原因 |

## 入口与页面

完整工作台承载任务管理，聊天侧栏承载当前制作。两者共用任务 ID、数据、版本与审批。设置只用于工作空间配置，不在侧栏提供一整套设置页。

### 任务首页

顶部显示制作空间名称和“新建任务”；下方按全部任务、待我处理、制作中、已完成、草稿分组，计数基于完整当前范围，搜索和分页不会让计数失真。保留状态精筛与搜索。

每条任务展示内容名称、内容风格、当前步骤、状态、完成进度、最近时间及一句下一步。成片已有封面时使用实际封面；尚无封面时显示风格与完成步数，不能把占位卡当真实产物。

任务分组包含“已归档”：归档任务只在此分组出现，行内提供“恢复”。归档是可逆标记，不移动文件；执行中、待评审或发布未核验的任务不能归档。

任务的主动作根据状态变化：查看评审、处理问题、查看进度、继续制作、编辑需求、查看成片或核验结果。待处理任务优先展示。进入某条任务后再显示详情，不存在独立的空“工作台”标签。

空态解释如何开始，并提供创建和检查工作目录。底部显示当前工作目录及自动同步状态，方便核对聊天任务为何尚未出现。

### 任务详情

归档任务在详情顶部显示归档说明条，隐藏执行、重做与重新提交需求，只保留“恢复任务”和只读查看；产物、评审历史与回执仍可打开。

首先显示任务名、实际运行状态、本次评审方式和下一步。宽屏左侧保留十步流程作为产物索引，右侧显示当前阶段；窄屏把流程改为步骤选择器。

阶段内容保留产物、检查、版本差异、发布记录四个入口。媒体使用实际文件预览，旧版本可比较；JSON 导入等技术恢复入口放到展开详情里。

当前阶段优先，用户主动查看旧步骤时不被轮询抢走。执行进入新的业务阶段时跟随进展。已完成任务默认进入成片阶段。

评审卡与对应产物在同一页面：通过并继续、要求修改、重做此步。修改意见绑定本版，展示上一版与本版差异；通过过的无关关口不再询问。发布关同时展示最终内容与账号，合并评审和发布确认。

暂停等待真实执行器停止；恢复复用已有产物。补充需求形成新版本；导出包括完整工程、来源与记录。发布待核验始终围绕原请求操作。

### 聊天侧栏

显示当前会话任务名称、当前阶段、进度与下一步；点击任务后，在对话右侧呈现完整任务详情。通过步骤选择器切换十步流程，查看产物、检查、版本差异和发布记录，直接批准、提出修改、播放或下载产物。窄栏使用单列布局。

从任务库选择未关联任务时建立关联。返回任务列表、切换任务、新建与重新提交需求均在右侧完成。聊天评审卡的“查看产物 / 提出修改”也打开右侧任务详情。设置仍放在全局工作台。

仅右侧标题栏的“展开 ↗”保留当前任务选择并打开全局工作台。普通任务点击不改变全局工作台的任务选择或页面。完整工作台回到随聊面板时沿用任务 ID，避免重复创建。

### 新建与重新提交需求

| 步骤 | 主要内容 | 次要内容 |
| --- | --- | --- |
| 内容与资料 | 要做什么、任务名、资讯/产品风格、真实来源与素材 | 受众、资讯截止时间、验收要求按需展开 |
| 交付规格 | 横竖版、目标时长、配音方式、画面后端、编码方式 | 尺寸、帧率、语速、对齐精度、时区按需展开 |
| 确认并开始 | 本次交付摘要、一次性评审策略、是否发布、平台账号与授权 | 免发布确认需明确原文，不能从免阶段评审推断 |

任一步均可保存草稿，跨页面和刷新继续编辑。最终开始是需求确认动作，不再追加第二次需求审批。重新提交需求复用同一任务的版本机制，不偷偷清空历史。

### 设置

| 分组 | 默认展示 | 交互 |
| --- | --- | --- |
| 工作目录 | 任务工作目录、结构预览、额外交付目录 | 填绝对路径后“使用此目录”；读取目标目录，不自动搬迁 |
| 制作偏好 | 常用音色、推荐评审、由当前对话还是独立模型完成内容 | 只有独立自动制作才展示模型提供商和模型字段 |
| 发布账号 | 发现浏览器、选择连接、检测实际账号 | 展示可识别的浏览器和账号；原始检测结果放详情 |
| 工具与诊断 | 各能力可用/不可用/待确认及重新检查 | 检测详情、自定义工具路径按需展开 |

设置有固定保存区，明确已保存、未保存或冲突。切换分类保留草稿，跨页面回来仍保留；冲突不覆盖用户输入。

目录切换立即对本插件生效，无需重启 DSH。当前目录存在运行或发布任务时拒绝切换，保留任务与数据；切换前要先处理未保存配置。目标目录已有设置时读取其设置，不拿旧目录覆盖。多窗口在旧目录发起写操作会被拒绝并重新加载目录。

任务统一位于 `<工作目录>/tasks/<任务ID>`。素材可继续放在作品目录；已有任务沿用实际数据根和 ID，目录不一致时先说明，不自动迁移或另建平行任务库。

## 状态与权限

界面区分制作中、等你评审、需要补充、执行失败、已暂停、已完成和发布待核验。能力未知不显示可用，账号未知不显示已登录。

模型与 UI 使用同一数据根，不是同一份示例路径。技能 get 时附带宿主当前配置；目录变更后重新加载技能取得新路径。无法写入时明确报告目录权限需求，不悄悄另建平行任务。

## 制作指导与插件职责（0.1.7）

保留任务库、会话右侧工作区、版本与依赖、需求时声明的评审、素材证据、媒体预览及发布核验。它们负责同一任务的一致记录；创作指导负责角度、主次、素材理解、镜头目的和作品检查。十步进度不规定所有作品采用同一种叙事。

技能入口优先说明如何判断制作路径，具体 CLI/恢复操作按需读取；制作参考为助手提供内容方法。共享的阶段指导同时写入 CLI 请求和 DSH 模型输入，避免工作台独立生成绕过技能的制作原则。UI 区分内容类型与视觉风格，并说明当前内置执行器实际采用固定模板。

当前对话入口由助手消费生成请求，不暗示自动唤醒聊天；模型与工具配置仍按创建时快照执行。选择当前对话的任务遇到生成阶段进入 generation-required，不因宿主存在 LLM 服务而误报空模型配置错误。

后续插件能力应按以下顺序扩展，而不是继续加长提示词：

1. 同一任务内的定制工程与成片导入协议：验证实际文件、输入版本和工程依赖，再生成产物清单与评审；保留旧版，不能直接修改状态或复用旧审批。优先解决专业制作工具与工作台脱节的问题。
2. 素材语义与可执行分镜：实际图像输入/查看证据，旁白段落与镜头解耦，结构化图层、多个素材、布局与动画时间点。自然语言说明作为设计意图，不能当作已经实现的工程。
3. 需求对应的质量检查与修改路由：明确哪些检查有证据、哪些待判断，把反馈送到实际负责的上游，避免只调参数却声称完成创意修改。内部迭代沿用用户已经声明的评审方式。

以上三项是后续设计范围，0.1.7 未实现通用工程导入、多模态素材理解或新的渲染器。

## 验收范围

验证聊天 CLI 新建后无需刷新即出现在列表；同一审批多入口幂等；修改仅影响必要阶段；草稿跨页恢复；三步向导保留全部参数；目录切换不搬任务并清除旧选择；过期窗口不能覆盖新目录；窄侧栏无横向溢出；暗色与减少动画可用。

本地预览使用明确标注的虚构内容、隔离任务目录与真实 FFmpeg 产物。它不代表真实内容模型、实际发布账号或日常 DSH 新版本已验收。
